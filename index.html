🎬 AI Short Film Studio

สตูดิโอทำหนังสั้นด้วย AI • เขียนบท • จัดฉาก • รวมวิดีโอ • ดาวน์โหลดไฟล์

รุ่นเริ่มต้นใช้ฟรี: เว็บนี้ช่วยสร้างบท/แบ่งฉากด้วย Gemini API (ถ้าคุณใส่ API key), อัปโหลดภาพฉากและเสียงเอง แล้วประกอบเป็นวิดีโอ MP4 ในเบราว์เซอร์ ไม่มีค่าโฮสต์ GitHub Pages แต่ AI API และโควตาสร้างภาพ/วิดีโออาจมีข้อจำกัด
อย่าใช้ API key ที่มีสิทธิ์สำคัญบนเว็บสาธารณะ ระบบนี้เก็บ key ไว้ในหน่วยความจำของหน้าเว็บเท่านั้น ไม่บันทึกลงไฟล์หรือ localStorage

1. ตั้งค่าเรื่องและบทหนัง

รับ API key ได้จาก Google AI Studio: aistudio.google.com/apikey โปรดตรวจสอบเงื่อนไขและโควตาก่อนใช้งาน

2. ตัวอย่างภาพและส่งออก

พร้อมจัดทำวิดีโอเมื่อเพิ่มฉากแล้ว

หากต้องการเสียงพูด ให้เตรียมไฟล์เสียงบรรยายภาษาไทยแล้วแนบที่นี่

การส่งออกใช้ทรัพยากรเครื่องของคุณ การแปลงเป็น MP4 จะโหลด FFmpeg WebAssembly จาก CDN ในครั้งแรก (อาจใช้เวลานานและต้องมีอินเทอร์เน็ต)

3. จัดการฉากหนัง

แต่ละฉากแก้บทได้ เพิ่มภาพนิ่งหรือคลิปวิดีโอของตัวเองได้ ระบบจะเรียงฉากตามลำดับ รวมเสียง และส่งออกเป็น MP4 คุณสามารถสร้างภาพ/คลิปจากบริการ AI ที่เลือกแล้วอัปโหลดได้
